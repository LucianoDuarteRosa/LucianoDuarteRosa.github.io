CasaMattos V2 — Gestão de Armazém

Sistema web (WMS) · Repositório privado

Evolução do meu primeiro sistema de endereçamento, feito em Java quando eu era supervisor de logística. Controla entrada de pallets, endereçamento físico (rua → prédio), movimentação pulmão → picking, estoque por lote/tonalidade/bitola em m², listas de separação e conferência com etiquetas de código de barras, dashboard de ocupação e importação/exportação em Excel.

O backend foi migrado de Node/Express para .NET 8 em Clean Architecture, com mais de 500 testes automatizados, e hoje também funciona como vertical de um ERP, replicando cadastros e estoque a partir de views read-only no SQL Server.
